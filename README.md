# Plataforma Acadêmica Inteligente

## Descrição
A Plataforma Acadêmica Inteligente é uma aplicação web voltada à gestão acadêmica, com foco em eficiência, segurança e personalização da experiência do usuário.

O sistema permite o gerenciamento completo de alunos, professores e coordenação, além de oferecer recomendações inteligentes com base no desempenho acadêmico.

---

## Objetivos
- Centralizar a gestão acadêmica
- Melhorar o acompanhamento do desempenho dos alunos
- Auxiliar na tomada de decisão da coordenação
- Aplicar conceitos de pensamento computacional em larga escala

---

## Funcionalidades

### Autenticação e Controle de Acesso
- Cadastro de usuários
- Login seguro
- Perfis:
  - Aluno
  - Professor
  - Coordenador

### Gestão Acadêmica
- Cadastro de disciplinas
- Matrícula de alunos
- Lançamento de notas
- Cálculo automático de médias

### Recomendação Inteligente
- Sugestão de conteúdos
- Identificação de dificuldades
- Apoio ao aprendizado personalizado

### Relatórios Gerenciais
- Dashboard acadêmico
- Indicadores de desempenho
- Relatórios por turma/disciplina

---

## Pensamento Computacional Aplicado

### Decomposição
O sistema foi dividido em:
- Autenticação
- Gestão acadêmica
- Relatórios
- Recomendação inteligente

### Reconhecimento de Padrões
- Login baseado em sistemas seguros
- Estrutura acadêmica inspirada em LMS
- Dashboards semelhantes a sistemas de BI

### Abstração
- Modelagem via UML
- Separação em camadas (arquitetura)

### Algoritmos
- Cálculo de média
- Classificação de desempenho
- Sistema de recomendação
